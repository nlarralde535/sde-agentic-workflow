# workflow-modification-plans

One file per change to the `/story-*` system, named `YYYY-MM-DD_<short-name>.md`, saved by
`/story-update-workflow` after its edit plan is approved.

Each records what was asked, what was decided, and what was changed — the record of *why* the
system looks the way it does. Nothing here is loaded at runtime.

The system's initial construction is not in this directory; it is `../plan_initial.md`.
